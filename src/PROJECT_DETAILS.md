# ERP & Inventory Management System

A large-scale enterprise ERP and Inventory Management platform developed for handling end-to-end business operations through a modular, scalable, and role-based architecture.

The system was designed to support multiple business domains including Sales, Purchase, Inventory, Finance, HRMS, POS, and Reports while maintaining high usability, performance, and workflow efficiency.

---

# Project Overview

The application provides centralized management for different organizational processes such as inventory tracking, billing, employee management, accounting, reporting, purchase flow, and sales operations.

The frontend architecture was designed with scalability and maintainability in mind, allowing multiple business modules and nested workflows to operate within a single unified platform.

# Key Features Implemented

## Role-Based ERP Architecture

* Developed dynamic role-based navigation and access management.
* Different users could access different modules based on permissions and roles.
* Built scalable nested routing structure for enterprise workflows.

## Multi-Tab Workspace System

* Implemented advanced tab-based navigation system.
* Users can:

  * Open multiple pages simultaneously
  * Navigate between tabs without losing data
  * Continue workflows without page refresh issues

## Draggable Tabs

* Added draggable tab functionality for better workspace customization and productivity.
* Improved user workflow handling for enterprise users working on multiple forms simultaneously.

## Reload & Exit Protection

* Added before-unload warning system.
* Prevented accidental page refresh or browser close during important form submissions or data entry processes.

## Enterprise Dashboards

* Built responsive dashboards with:

  * KPI cards
  * Business analytics
  * Graphs and charts
  * Transaction summaries
  * Operational metrics

## Dynamic Tables & Data Management

* Developed reusable table components with:

  * Column-wise sorting
  * Ascending/descending filtering
  * Dynamic rendering
  * Pagination-ready architecture

## Dynamic Z-Index Management

* Managed complex layered UI architecture using dynamic z-index handling.
* Solved overlapping issues for:

  * Nested modals
  * Internal pages
  * Dropdowns
  * Popups
  * Layered enterprise components

## GSTIN Verification Integration

* Integrated external GSTIN verification API.
* Automatically fetched and validated business details based on GSTIN number.

## Beginner Onboarding Navigator

* Added guided onboarding experience for first-time users.
* Implemented highlighted navigation walkthroughs for better usability and user adoption.

## Authentication & Workflow Handling

* Built secure login and access workflow.
* Managed validations, loading states, error handling, and route protection.
